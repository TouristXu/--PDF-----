# PDF操作工具 - 部署说明

## 概述
本工具是一个PDF综合编辑器，支持多种PDF操作功能。

## 功能列表
1. PDF插入：在PDF文件中按指定间隔插入其他PDF页面
2. PDF分割：将PDF文件按指定页数分割成多个文件
3. PDF页面交换：交换PDF文件中的指定页面
4. 指定导出页：从PDF文件中导出指定页面（支持批量处理）
5. PDF批量重命名：批量修改PDF文件名
6. PDF重排序：按Excel数据对PDF文件进行排序
7. PDF页面：反转页面顺序或旋转页面
8. PDF页面逆序：将PDF文件的页面顺序反转（支持批量处理）
9. **交叉合并**：将两个PDF文件按页交叉合并（用于扫描件正反面拼接）
10. 批量提取：从多个PDF文件中提取指定页面
11. 批量追加页：将源PDF页面追加到多个PDF文件
12. PDF合并：将多个PDF文件合并到一个主PDF后面
13. 批量单页追加：从多个PDF中各提取一页并批量追加到主PDF
14. 学生班级PDF合并：根据Excel数据匹配学生和班级PDF
15. Excel批量导出PDF：将Excel文件转换为PDF
16. Word批量导出PDF：将Word文件转换为PDF

## 运行方式
双击运行 `PDF编辑器_dir.exe` 即可启动程序。

## 系统要求
- Windows 10 / Windows 11（64位）
- 无需安装Python环境
- 无需安装其他依赖

## 使用说明

### 交叉合并功能（新增）
此功能用于将两个PDF文件按页交叉合并，特别适用于扫描件的正反面拼接。

**使用场景**：
- 有两份158页的PDF（79人×2页）
- PDF_A：正面扫描（封面、申请表正面）
- PDF_B：背面扫描，需先逆序处理（封面背面、申请表背面）

**操作步骤**：
1. 在功能选择区选择"交叉合并"
2. 选择PDF_A（正面扫描）
3. 选择PDF_B（背面扫描，已逆序）
4. 设置参数：
   - PDF_A每次取页数：1（每人1页正面）
   - PDF_B每次取页数：1（每人1页背面）
   - 合并份数：79（79人）
5. 选择输出目录
6. 点击"预览合并方案"查看详细信息
7. 点击"执行操作"完成合并

**合并模式**：
```
A取1页 → B取1页 → A取1页 → B取1页...
输出结果（每人4页）：
- 封面正面（A第1页）
- 封面背面（B第1页）
- 申请表正面（A第2页）
- 申请表背面（B第2页）
```

### 其他功能
1. 启动程序后，在顶部功能选择区选择要使用的功能
2. 按照界面提示选择文件和设置参数
3. 点击"执行操作"按钮开始处理
4. 处理完成后会显示成功/失败信息

## 注意事项
1. 所有操作都会保留原始文件，输出到指定目录
2. 处理大文件或大量文件时请耐心等待
3. 如果操作失败，会显示详细的错误信息
4. 交叉合并功能在处理过程中会在终端打印详细进度日志
